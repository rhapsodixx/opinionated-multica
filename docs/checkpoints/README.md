# Human review mock screens

These are proposed workflow illustrations, not screenshots of a deployed system.
The task, people, approvals, commits, test results and coverage values are fictional.
No comment, review, approval or merge was submitted.

- `before-code.html`: Multica issue activity, versioned Git plan links, human approval comment and workflow handoff.
- `before-merge.html`: GitHub PR evidence, code review and human merge actions.
- The PNGs are screenshots of these static HTML files in Chromium.

The images were shown in chat before the README was changed.
Both renders were inspected for readable text and clipping. They use system fonts and need no external assets.

To update a screen, edit its HTML. Open it in Chromium at a 1480-pixel viewport.
Capture the `.capture` element at 1.5× scale after the fonts load.
Inspect the output before replacing a PNG.

Supported product features are linked in the main README. The status names, approval wording and runner behavior are proposed conventions.
Image rendering checks do not certify Multica handoffs, approval matching, PR publication or product functional UI tests.
