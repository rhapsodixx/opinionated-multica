# Potato identity

`potato-logo.png` shows one plain potato in manga ink style on a white background.
It has no face, eyes, hands, limbs or character accessories. It replaces the earlier tomato mascot.
The README explains the potato-inspired philosophy and credits poteto (Lauren Tan) and the other creators.

The square image was generated with the built-in image generation tool on 22 November 2026.
Earlier images remain in Git history.

Generation prompt:

> Create a dead-simple square 1:1 logo illustration: JUST ONE PLAIN POTATO, drawn in manga ink style, on an entirely pure flat WHITE (#FFFFFF) background. An ordinary irregular oval potato lying diagonally, subtly warm tan, a clean bold hand-drawn black contour and a small amount of manga halftone/screentone shading to suggest the surface. Extremely simple, calm and understated. This is food, NOT a character. Absolutely NO face, NO eyes, NO mouth, NO eyebrows, NO hands, NO arms, NO legs, NO feet, NO clothing, NO accessories, NO action marks, NO sparkles, NO text, NO letters, NO frame, NO extra objects, NO shadow outside the potato. Do not arrange surface marks like facial features. The single potato is centered with generous white margin, fully visible, recognizable as a potato, clean small-icon readability. Keep the background white, not cream or gray.
